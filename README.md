# CocktailHub

A cocktail e-commerce front-end — browse the menu, read about the bar, and place an order. Plain HTML, CSS and JavaScript: no framework, no build step, no backend.

## Features

- Hero section — "Craft Cocktails Delivered Fresh"
- Menu of cocktails with photos (images from [TheCocktailDB](https://www.thecocktaildb.com))
- About section — "Crafted with Passion"
- Order form with an order-confirmation screen (front-end demo — orders are not sent anywhere)
- Responsive design, Google Fonts (Poppins + Playfair Display)

## Tech stack

HTML, CSS, JavaScript, Google Fonts

## Run it locally

Open `Project 2/index.html` in a browser, or serve it over HTTP:

```bash
cd "Project 2"
python -m http.server 8000
# then open http://localhost:8000
```
